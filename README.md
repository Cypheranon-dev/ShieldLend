# ShieldLend

**Private lending and staking for the Cypher ecosystem.**

Lend your liquidity to markets and earn **0.02% per hour**. Borrow Cypher (CYP) against BTC, SOL, or ETH collateral at a rebated **0.015%** rate. Stake CYP for additional shielded yield.

Integrated with [Mask Wallet](https://github.com/Cypheranon-dev/Maskwallet) and [Mask Swap](https://github.com/Cypheranon-dev/Maskswap). Built as a foundational piece of the Cypher CIP vision — privacy by default, post-quantum ready.

## Features (demo)

- Live price charts (ETH / BTC / SOL / CYP) with simulated history
- Market liquidity chart
- Shielded lend ETH / BTC / SOL → earn 0.02%/hour
- Shielded borrow CYP against collateral → 0.015% rebated rate
- Stake CYP → 0.015%/hour shielded yield
- Test balances display and position tracking
- Black + orange Cypher theme
- Direct links to Mask Wallet and Mask Swap
- GitHub Pages ready
