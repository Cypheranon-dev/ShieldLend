# ShieldLend

**Basic private lending for the Cypher ecosystem.**

Lend your liquidity to markets and earn **0.02% per hour**. Borrow Cypher (CYP) against BTC, SOL, or ETH collateral at a rebated **0.015%** rate.

Integrated with [Mask Wallet](https://github.com/Cypheranon-dev/Maskwallet) and [Mask Swap](https://github.com/Cypheranon-dev/Maskswap). Built as a foundational piece of the Cypher CIP vision — privacy by default, post-quantum ready.

## Features (basic demo)

- Lend ETH / BTC / SOL liquidity → earn 0.02%/hour
- Borrow CYP against collateral → 0.015% rebated rate
- Live rate display and position tracking (demo balances)
- Black + orange Cypher theme
- Direct links to Mask Wallet and Mask Swap
- GitHub Pages ready
